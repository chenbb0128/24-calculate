以下材料必须按实际上载审核的版本填写。当前代码已接入自有 HTTPS 服务 `https://calc-api.pdurl.cn`，好友房、快速匹配、排行榜和服务端进度依赖联网后端；旧版“本地模拟/单机”描述只适用于历史原型，不能直接用于当前正式联网包。

## 1. 场景说明（可直接粘贴）

```text
游戏主界面采用竖屏卡片式布局，使用深蓝与紫色渐变背景，搭配星点、数字和运算符装饰，突出“24”这一目标数字。顶部显示金币和设置入口，中部显示游戏标识及“闯关模式、好友对战、无尽模式”三个主要入口，底部提供每日挑战、每日任务、更多功能和闯关进度信息。整体风格简洁、明亮、偏益智休闲，不包含血腥、暴力、恐怖或博彩元素。

算题场景以倒计时、当前题目进度、目标数字24和四个数字卡片为核心。玩家依次点击第一个数字、运算符和第二个数字完成计算，界面会显示得分、连击、撤销、提示和重置等操作。计算过程仅允许整数中间结果，并拦截除数为零等无效操作。

闯关场景展示章节和关卡列表，已解锁关卡可进入，未解锁关卡以锁定状态显示；完成关卡后展示得分、星级、连击、错误次数和金币奖励。每日挑战场景提供固定题目和当日规则；无尽模式场景连续生成题目并记录答题数、最高分和连击；好友对战场景展示房间信息、双方答题进度和竞速结果。主题商店和任务页面用于查看金币、主题皮肤和任务奖励。
```

## 2. 玩法说明（可直接粘贴）

```text
《24点算术》是一款休闲益智类数学计算小游戏。每道题提供四个数字，玩家需要在规定时间内将四个数字各使用一次，通过加法、减法、乘法和除法组合运算得到目标数字24。基本操作流程为：点击第一个数字，点击运算符，再点击第二个数字；计算后的结果会与剩余数字继续组合，直到只剩一个结果。系统会自动校验题目是否有解，并限制中间结果为整数，除数为零和非法运算会被拦截。

游戏包含闯关模式、每日挑战、无尽模式和好友对战入口。闯关模式按章节逐步解锁关卡，每关包含多道题，完成后按照得分、用时、连击、错误和提示使用情况评定星级。每日挑战每天提供固定的三道题，并轮换特殊规则，例如限制某类运算、不能撤销、必须使用指定运算或快速完成。无尽模式答对后继续生成下一题，随着答题推进逐步提高难度并缩短时间，答错或超时会结束本局。好友对战使用同一组题目进行限时竞速，服务端校验双方进度和结果，按答对题数、得分和用时比较胜负；联网失败时不会伪造结算或发放服务端奖励。

玩家可通过完成关卡、每日挑战、无尽模式、好友对战和任务获得金币。金币仅用于兑换和装备界面主题皮肤，不用于购买随机结果、赌博、现金提现或其他具有现金价值的商品。金币、解锁和商城结果由服务端校验并与账号关联；本地缓存只作为按账号隔离的客户端缓存。提示和撤销属于辅助功能，可按平台规则接入激励广告；不设置充值、抽奖、红包、会员或虚拟物品交易功能。

游戏没有角色养成、装备强化、战斗、攻击或生命值系统，主要目标是训练心算、四则运算、专注力和逻辑思维。玩家成绩、解锁进度、金币和主题设置与账号关联保存，服务端是正式数据的权威来源。
```
