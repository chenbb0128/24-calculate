# 三火算术练习｜原生微信小游戏

这是原生微信小游戏 Canvas 前端，当前只维护本目录，不再依赖 Godot 原型。

## 打开和运行

1. 打开微信开发者工具，导入：`D:\微信小游戏\frontend\wechat_game`。
2. 项目类型为“微信小游戏”，竖屏 Canvas 入口为 `game.js`。
3. 正式 AppID：`wx1e7ac815548c561c`。
4. 当前默认使用本地题库。后端地址配置在 `src/services/api_client.js`，正式环境必须使用 HTTPS 合法域名。
5. `127.0.0.1` 默认关闭，真机不会把它误认为手机自身地址。

## 已实现

- 首页、关卡选择、200 个闯关关卡和 20 关分页
- 闯关、每日挑战、无尽、好友房间和匹配模式
- 数字 → 运算符 → 数字的点击操作
- 题目生成、解法验证、整数结果、题目去重和难度递增
- 自动下一题、整关结算、撤销、提示、计时、连击、星级和本地存档
- 撤销/提示首次免费，后续预留激励广告
- 设置、背景音乐、按键音效、独立音量和音乐切换
- 主题商城、数字卡片、运算符样式和结算特效
- 每日任务、成就、排行榜、本地最好成绩和分享房间
- 切后台暂停、恢复、联网失败提示和运行错误恢复画面
- 分享链接冷启动和热启动处理

音频资源位于 `assets/audio/`，包含两首背景音乐和点击、选牌、运算、合成、成功、失败、倒计时音效。

## 后端接入说明

正式后端开启后，服务端应作为以下数据的权威来源：

- 用户身份
- 题目和题目 hash
- run_id、房间和匹配状态
- 分数、关卡进度、星级
- 金币、奖励和商城购买
- 好友对战结果和排行榜

正式 HTTPS 后端开启后，闯关、每日挑战、无尽和好友对战都必须先获得服务端运行记录并由服务端确认结算；网络失败时只显示重试提示，不保存本地奖励、解锁、任务、统计或排行榜成绩。只有明确关闭正式后端的离线开发模式才允许本地体验和机器人对手。

广告 ID 集中在 `src/services/platform.js`，占位 ID 会静默降级，不会影响游戏。正式上架前需要替换真实广告位，并配置合法域名、隐私协议、分享素材和服务端 HTTPS。

重点真机验收：最后一步得到 24 是否自动进入下一题、重新开始是否立即生效、每日完成后是否锁定、分享热启动是否进入房间、切后台恢复、弱网、广告失败、音频失败，以及 375×667 小屏点击区域。

上线前还需要在微信开发者工具中手动确认：正式后端已替换为 HTTPS 合法域名、广告位 ID 已替换、云环境/隐私协议/分享素材已配置，并完成真机冷启动、切后台、弱网和连续点击测试。`prelaunch_audit.js` 只检查前端本地可验证内容，不会代替后端验收。
